# Housing Void Property Template Pack

This template pack is based on recurring documents and workflows seen in local council and housing association void management processes.

It is designed for:
- end-of-tenancy inspections,
- void property handover,
- pre-termination surveys,
- repair snagging,
- key return records,
- and mobile capture flows that generate a polished report after the visit.

The pack is written so it can be used as:
- a manual office template set,
- a mobile app data model,
- or a future automated report generator.

---

## 1. Common workflow

A practical void workflow usually looks like this:

1. Tenant gives notice or vacancy is identified.
2. Pre-termination inspection is arranged.
3. Void notification is logged internally.
4. Property condition is checked room by room.
5. Meter readings, keys, access notes, and safety issues are captured.
6. Repairs and remedial work are listed.
7. Final handover / keys return is recorded.
8. A clean void inspection report is issued.
9. Repairs and lettings teams use the report to plan next actions.

## 3. Template 1 — Void Notification Form

Used when a tenancy is ending or when a property is expected to become vacant.

### Typical users

- Lettings officer
- Repairs coordinator
- Neighbourhood manager

- Vacancy date

## 11. Product opportunity note

This template set is a strong candidate for automation because the underlying process is repetitive and structured.

A good future feature would:
- let the inspector choose a property,
- walk through each room on mobile,
- attach photos and notes,
- capture meter readings and keys,
- and generate a polished void report automatically.

That would make the mobile app useful not only for electrical certificates, but also for housing voids and tenancy exit workflows.
